# Session 2026-11-11-01 — Frontend redesign v2

## Goal / request
Owner: improve the frontends of the 5 FREE-API repos, one by one,
starting with the GitHub Analyzer (DevMetric), using the components
and design knowledge he has supplied over time (UI Layouts library,
saved-references design items, frontend-preferences brain) — and
tell him, step by step, anything he needs to provide (API keys etc.).

## Direction chosen (from his own brain files)
- Hero anatomy (frontend-preferences): brand mark, bold two-line
  display title, supporting line, feature chips.
- Interface patterns: stat tiles + grouped panels instead of bare
  figures; skeleton shaped like the real UI; empty/error states kept.
- Anti-tell list honoured: no purple/blue gradients (no gradients at
  all), no glass, no badge-above-headline, no serif-italic accents,
  no coloured left-border cards, no scroll-fade gimmicks.
- Colour: near-black + ONE accent (GitHub green), light data surface
  (his light-theme default), dark only for header/hero.
- Type pairing by feeling: Sora display + Inter UI + JetBrains Mono
  for data (monospace = tech/data per his typography vocabulary).
