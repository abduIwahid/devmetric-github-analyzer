About this project

I built DevMetric because the number I kept wanting — how much of a GitHub profile is original work, and in which languages — is not shown anywhere on GitHub itself. The interesting constraint is the API's 60-requests/hour unauthenticated limit: the obvious way to get a language breakdown (one /languages call per repository) burns that quota on a single profile. DevMetric aggregates the repository list it already fetched instead, so a full analysis costs two or three calls — and repeat views are served through ETag conditional requests that GitHub does not count against the limit at all.

Part of a series of small, dependency-free apps I built against free public APIs to practise working within real rate limits and payload shapes.
